Employee Management SystemA CLI-based Python application that demonstrates fundamental Object-Oriented Programming (OOP) principles including encapsulation, inheritance, method overriding, and subclass verification.FeaturesEncapsulation: Uses private attributes (__employee_id, __salary) with getter and setter interfaces.Inheritance: Derived Manager and Developer classes inherit core functionality from the base Employee class.Method Overriding: Custom display() implementations across child classes adapt output formats dynamically.Dynamic Lifecycle Management: Explicit initialization (__init__) and automated destruction tracking (__del__).Subclass Checking: Native runtime validation of class hierarchies using issubclass().Class Architecture1. Base Class: EmployeeAttributes: name, age, __employee_id (Private), __salary (Private).Methods:Getters / Setters for private fields.display(): Outputs default profile data.__del__ Tracking: Prints a confirmation message upon object removal.2. Child Class: ManagerInherits: EmployeeExtended Attribute: departmentOverridden Method: display() (Includes department context).3.
